# Sources and licenses

This distribution contains the Small Brains Club Othello application and its
trained policies. The existing project's GPL-2.0 license is included as LICENSE.

## ONNX Runtime Web

ONNX Runtime Web 1.31.1, Microsoft and contributors.
https://github.com/microsoft/onnxruntime

The browser runtime is redistributed under its MIT license. Preserve
vendor/LICENSE and vendor/ThirdPartyNotices.txt. vendor/runtime.json records
the version and SHA-256 of the bundled runtime files.

## Training data attribution

Othello transcripts: Takuto Yamana / Egaroucid, Training Data v0002.
https://github.com/Nyanyan/Egaroucid/releases/tag/training_data_v0002

This package includes trained model weights, not the original training
transcripts, derived position datasets, or benchmark fixtures.

The illustrations are the SVG assets created for this project. No external
fonts, image CDNs, analytics services, or model servers are required.
