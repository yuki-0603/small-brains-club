# ちいさな脳のオセロ / Small Brains Club

流行りのショウジョウバエのコネクトームにオセロ覚えさせることできるかな？と初めたが、従来の機械学習の感覚全然通用しないわ漏れ積分発火モデル自体イマイチ理解しきれなかったわ推論は軽い癖に学習はめっちゃVRAMいるわで諦めた結果出来た、普通の機械学習モデルにオセロ覚えさせたゲームです。割と人間相手にしてる感覚あって気に入ってますが、10Mモデルはまだ学習中で伸びしろあります

クラゲ・ミツバチ・ヤモリ・リクガメと遊べるオセロです。AIはニューラルネットワークだけで一手を選び、先読み探索は使いません。モデルの重み、HTML、画像、推論用WASMをすべて同梱しています。ダウンロード後の対局にネット接続やアカウントは不要です。

オンライン版：https://small-brains-club.tegami1870.workers.dev/

## 起動

Python 3.9以降と、WebAssembly SIMDに対応したブラウザ（Chrome、Edge、Firefox、Safariなど）が必要です。Pythonの追加パッケージ、Node.js、GPUは不要です。

1. このディレクトリ全体を保存します。ZIPの場合は先に展開してください。
2. OSに合うファイルを実行します。
   - Windows：`start.bat`
   - macOS：`start.command`（またはターミナルから `sh start.sh`）
   - Linux：ターミナルから `sh start.sh`
3. ブラウザで `http://127.0.0.1:8000/index.html` が開きます。画面が開かない場合は、表示されたURLを手動で開いてください。

起動したターミナルは遊んでいる間そのままにしてください。終了は `Ctrl+C`。ポート8000が使用中なら `python3 serve.py --port 0` で空きポートを利用できます。Windowsでは `py -3 serve.py --port 0` が使えます。

`index.html` をファイルとして直接開くと、ブラウザの制限により重みやWorkerを読み込めません。その場合は起動案内が表示されます。上記のスクリプトは、このフォルダの公開ファイルだけを自分のPC内（127.0.0.1）で配信します。AIの計算はブラウザ内で行います。

## 遊び方

最初は軽量なクラゲ（10K）ですぐに対局できます。ヤモリ（3M）は背景で準備し、ミツバチ（1M）・リクガメ（10M）は選択したときに読み込みます。「あそぶ」で新しい対局を始めるまで、対局中の相手は切り替わりません。先手・後手、合法手のガイド、一手戻す、対局の保存・復元、終局ポップアップに対応しています。

## 含まれるもの

| パス | 内容 |
|---|---|
| `index.html`, `garden.css`, `garden.js` | 対局画面 |
| `rules.js`, `tiny.js`, `model-worker.js` | オセロのルールと端末内推論 |
| `models/`, `models.json` | 4モデルの重み・構造情報・SHA-256 |
| `vendor/` | ONNX Runtime Web 1.31.1とWASM、ライセンス |
| `assets/` | 生きものなどのSVGイラスト |
| `serve.py`, `start.*` | 追加パッケージ不要のローカル起動 |
| `MODEL_CARD.md` | モデルの構成と配布形式 |
| `MANIFEST.json`, `SHA256SUMS` | 同梱ファイルの一覧と検証用ハッシュ |

学習用の生棋譜やデータセット、認証情報は同梱していません。

## 静的ホスティング

このディレクトリをそのままGitHub Pagesなどの静的ホストに置いても動きます。リンクは相対パスなので、リポジトリ名を含むサブディレクトリにも配置できます。サーバ側のPythonや推論APIは不要です。`.wasm` を `application/wasm` として配信してください。外部CDNには依存していません。
